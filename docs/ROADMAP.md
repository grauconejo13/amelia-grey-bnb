# Roadmap

## Current baseline
- [x] React/Vite frontend and routed pages
- [x] Static room data and room presentation components
- [x] Mock booking form clearly labeled as non-submitting
- [ ] Automated component/interaction tests
- [ ] Verified accessibility audit across the user journeys
- [ ] Documented deployment and live smoke test

## Next, before feature expansion
1. Add focused tests for navigation, room detail, and demo booking messaging.
2. Audit keyboard navigation, form labels, modal focus, and responsive layouts.
3. Fix confirmed defects without introducing a backend.

## Out of scope without a new product decision
Real reservations, live room availability, authentication, payments, customer records, and reservation email delivery.

The checkboxes distinguish repository-level evidence from future work; they do not indicate independent manual test verification.
